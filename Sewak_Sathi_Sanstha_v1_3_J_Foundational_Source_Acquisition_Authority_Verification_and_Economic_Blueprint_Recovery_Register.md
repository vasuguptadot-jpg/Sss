## 0. THE OPERATING RULES OF THIS INSTRUMENT

### 0.1 The single governing principle

**[P]** v1.3-I established that **the analytical method is complete and the foundational subject is not established.** v1.3-J therefore performs **no further analysis of the relationship.** It performs one operation:

> **Convert every demonstrated absence into a controlled acquisition item — with a named provider, a named authority, a named verification standard and a named blocking consequence — and change nothing else.**

**[P] Rule J-1 (No Source, No Fact, No Closure).** Adopted verbatim as the instrument's governing principle. **An item moves only on evidence. It never moves on analysis, elaboration, restatement or the production of a more detailed register.**

**[P] Rule J-2 (The Final Absolute Rule).** *"The organisation is not permitted to become more 'real' merely because the documentation becomes more elaborate."* **This instrument is the most elaborate documentation yet produced about a set of facts that do not exist in the record. Rule J-2 is the reason it confers nothing.** **It is a request mechanism, not a foundation.**

**[P] Rule J-3 (The Order Is Never Reversed).** **SOURCE → VERIFICATION → VALIDATION → DECISION → IMPLEMENTATION.** **No Part of this instrument permits a later stage to supply an earlier one. In particular: no pilot measurement may supply a source document (Part VI, Part XX); no professional opinion may supply a fact (Part XII); no human decision may supply evidence (Part XII); no wording may supply authority (Part IX).**

## II.7 The readiness state machine

**[P]** **Ten states, in one permitted direction.** No item advances except on the event named in its transition. **A failure at any stage returns the item to the appropriate earlier state — never forward.**
